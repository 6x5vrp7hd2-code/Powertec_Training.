LV Main Distribution

The single system every other module ultimately connects back to, and the area DNO experience least prepares an engineer for.

Purpose

The single system every other module in this programme ultimately connects back to — and the one area where DNO SAP experience least prepares an engineer, because LV in a data centre is not the simple, repetitive network it is on the distribution side.

Normal State

Transformer feeds an LV switchboard, which supplies principal distribution boards, typically with bus-section and bus-tie breakers enabling the board to be split or joined.
