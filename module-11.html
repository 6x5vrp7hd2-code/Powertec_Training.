The UPS — Architecture, Sources, Synchronisation and Load

Section 11 from the expanded Data Centre Electrical Specialist’s Guide.

The double-conversion UPS architecture described (VFI class per IEC 62040-3) remains the dominant topology specified for critical data centre loads worldwide, precisely because it fully decouples the protected load from all upstream disturbances — the inverter, not the utility, manufactures the waveform the load actually sees.

Additional context:

IEC 62040-3 UPS classification

The international standard defines three UPS performance classes by a three-letter code (commonly summarised as VFD, VI, VFI): VFD (Voltage and Frequency Dependent) — the simplest “offline” /standby topology, where the load runs directly off the raw mains most of the time and only switches to the inverter on a disturbance; VI (Voltage Independent) — a “line-interactive” topology that regulates voltage but still passes mains frequency through; and VFI (Voltage and Frequency Independent) — the double-conversion topology the guide describes, where the inverter continuously manufactures the output regardless of upstream voltage or frequency variation. VFI/double-conversion is the class specified for essentially all serious data centre critical loads, since it is the only class providing genuine, continuous decoupling from the utility.

Static bypass switch (SSW) speed and thyristor technology

Thyristor-based static switches can transfer load between sources in a few milliseconds specifically because thyristors are solid-state semiconductor devices with no moving parts — unlike a mechanical contactor, which needs physical contact travel time, a thyristor can be commanded to conduct or block current almost instantaneously (limited mainly by the AC waveform’s zero-crossing points), which is why the SSW — not the mechanical maintenance bypass — is the device relied upon for automatic, load-preserving transfers on an inverter fault.

UPS parallel systems and load-sharing control

Modern parallel UPS systems use a dedicated parallel communication bus between modules (often a redundant, ring-based digital link) specifically so that a failure of the communication link itself doesn’t cause a loss of synchronisation between modules — a design lesson learned from earlier- generation parallel UPS systems where a single point of failure in the inter-module link could cause “hunting” (modules fighting each other for load share) or a complete loss of parallel operation.
